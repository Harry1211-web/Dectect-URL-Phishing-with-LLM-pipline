# Protect yourself from tech support scams (Microsoft)

Scammers use scare tactics to sell support for problems that do not exist, or to steal personal and
financial information and install malware through remote access.

## Microsoft error messages never include phone numbers

A web page showing a Windows or Microsoft "error", "virus detected" or "your PC is blocked" message
together with a support phone number is a scam. Microsoft error and warning messages never include
phone numbers, and Microsoft never makes unsolicited calls or emails asking for personal or
financial information or offering to repair your computer.

## Web scams: fake blue screens and browser lockers

Malicious ads on dubious sites (pirated software, video downloads) redirect to fake blue-screen or
Windows activation pages. They switch the browser to full screen, open pop-ups that will not close,
disable Task Manager and play audio warnings to push the visitor to call.

## Phone scams

Cold callers claim to be from Microsoft, sometimes with spoofed caller ID showing a real support
number. They may know your name, ask you to install remote-access software, then ask for a one-time
fee or subscription. Microsoft never asks for payment in cryptocurrency or gift cards.

## What to do

Do not call numbers shown in pop-ups or error messages; close the browser. Download software only
from Microsoft or its partners. If a scammer had access: uninstall the apps they installed, run a
full scan, install updates, change passwords and dispute card charges. Report at
microsoft.com/reportascam.
